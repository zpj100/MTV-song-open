# MTV 点歌 · 发行包

家庭 KTV 点歌安装包。本仓**只挂 APK**，源码在私有仓，不在这里。

- Android 5.0+（含机顶盒）APK，2.0.0 基于麦动 KTV 合并
- 不要下载发行页上 Gitee 自动列出的 zip / tar.gz（那是 tag 源码快照，不是安装包）

## 现在就装

1. 打开 [Gitee 发行页](https://gitee.com/zpj100/MTV-song-open/releases) 或 [GitHub 发行页](https://github.com/zpj100/MTV-song-open/releases)
2. 下载最新 `mtv-song-*.apk`（盒子用 FAT32 U 盘拷入，系统「本地安装」）
3. 装完打开即可点歌，不必填电脑地址

当前包：

- APK 2.0.0：https://gitee.com/zpj100/MTV-song-open/releases/download/v2.0.0/mtv-song-2.0.0.apk
- 备用：https://github.com/zpj100/MTV-song-open/releases/download/v2.0.0/mtv-song-2.0.0.apk
- 仓内直链：`mtv-song-2.0.0.apk`

应用内「检查更新」对照本仓最新发行，无需登录。

## 2.0.0 功能

- 内置 81,801 首歌曲、4,807 位歌星、63 个分类歌单、7 个排行榜，离线可查
- 首页采用麦动 KTV 样式，左侧导航与遥控器焦点操作
- 排行榜、歌名、歌星、语种、字数、收藏、歌单、已点、已唱、下载、U 盘、影片
- 歌曲检索、首字母键盘、分页浏览、歌星头像与歌手歌曲
- 点播、批量点歌、置顶、收藏、文件管理，队列状态实时同步
- FFmpeg 原生解码，小窗与全屏连续播放，原唱 / 伴唱切换
- 后台下载、断点恢复、失败重试、完整性校验、预留空间与自动清理
- 本地存储、U 盘、OpenList 网盘统一扫描、检索和保存
- 全屏播放页手机点歌二维码
- 关于页面显示版本号，并链接 https://gitee.com/zpj100/MTV-song-open

## 说明

- 默认离线使用，下载歌曲、歌星头像和检查更新时才访问外网
- 应用更新来源为 Gitee Release `zpj100/MTV-song-open`，只识别 `.apk` 附件
- 源码仓私有，本仓不要推源码
