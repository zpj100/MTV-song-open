# MTV 点歌 · 发行包

家庭单机点歌安装包。本仓**只放发行文件**，源码在私有仓，不在这里。

- Android 3.0+（含机顶盒）APK
- Windows 7 64 位绿色 zip（有则挂在同一发行页）

## 现在就装

1. 打开 [Gitee 发行页](https://gitee.com/zpj100/MTV-song-open/releases) 或 [GitHub 发行页](https://github.com/zpj100/MTV-song-open/releases)
2. 下载最新 `mtv-song-*.apk`（盒子用 FAT32 U 盘拷入，系统「本地安装」）
3. 装完打开即可点歌，不必填电脑地址

当前包：

- APK 1.5.1：https://gitee.com/zpj100/MTV-song-open/releases/download/v1.5.1/mtv-song-1.5.1.apk
- 备用：https://github.com/zpj100/MTV-song-open/releases/download/v1.5.1/mtv-song-1.5.1.apk

应用内「检查更新」对照本仓最新发行，无需登录。

## 说明

- 默认不联网。扩充曲库、直播、检查更新时才访问外网
- 网上搜歌只走 Internet Archive / Wikimedia / Openverse
- 源码仓私有，本仓不要推源码
